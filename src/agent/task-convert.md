Convert each document in `/in` into a clean, structured {{FORMAT_NAME}} file. Choose your own approach and your own tools.

{{INSTRUCTIONS}}

## Output

1. For each document, write `/out/converted/<document file name>{{EXTENSION}}`. For example `/in/report.pdf` gives `/out/converted/report.pdf{{EXTENSION}}`.
{{FORMAT_RULES}}
2. Write `/out/answer.md`: two to five lines. Say what you converted, what you could not convert, and anything the reader must know (for example "page 4 is a chart; its values come from a model reading of the image").

Keep all the content, in the original order and the original language. Do not summarize unless the instructions ask for it. Mark content that a model read from an image as such.

Before you stop, open each output file and compare it with its document. Fix anything important that is missing. Then stop.
